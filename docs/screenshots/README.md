# 全页面截图

共 24 个页面、48 张截图：前台 14 个页面，以及管理端首次初始化、登录和 8 个模块。桌面视窗 1920 × 1200，手机视窗 390 × 844，均为浏览器完整页面截图；滚动条会占用部分图片宽度。

[打开可切换的截图册](index.html)（下载源码后可用浏览器直接打开此 HTML 文件）。

所有截图来自隔离的本地演示环境。目标 example.com、文档示例 IP、节点、延迟、套餐、用量和调用记录均为演示数据，不是线上测量，不含真实账号或凭据。截图不代表已接入实际节点服务。

管理端没有用户名或默认密码：首次访问 /admin 自设 12–128 字符密码，公网安装额外需要服务器 .env 中的 KY_SETUP_TOKEN。日常登录只使用自设密码。初始化和登录截图中的密码、令牌输入框均为空。

本次按自有 DNSPup 源站恢复六类工具的表单、结果列、地图/解析统计和说明区。程序默认关闭广告；本截图为展示原广告位结构，启用了站长自行配置的文字示例广告。图中省份颜色取决于示例节点；没有测量的省份保持灰色。批量检测、本地网络、监控任务、平台用户中心与未授权的高级 API 功能仍不在本轮范围内。
